What is Project KRNL?

Project KRNL is an operating system project focused on building and experimenting with the different parts of an operating system.

The project has gone through several stages. What started as KRNL-DOS eventually grew into something much larger.

The current development version is internally using the codename KRNL 1. KRNL 1 is a codename, not the final name of the project.

Current development

KRNL is currently being developed toward a graphical operating system.

Project history
